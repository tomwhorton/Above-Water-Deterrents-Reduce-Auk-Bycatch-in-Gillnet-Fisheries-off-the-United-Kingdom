## Abstract

Seabird bycatch in gillnet fisheries is a globally pervasive conservation issue, yet evidence for effective, scalable mitigation remains limited. In a gillnet fishery of the United Kingdom (1,057 observed fishing sets), we evaluated two above-water deterrents (AWDs), "scarybird" kites and looming-eyes buoys, for reducing auk bycatch. Both deterrents significantly reduced the likelihood of auk bycatch and the magnitude of bycatch when it occurred. Kites reduced bycatch occurrence by approximately 71%, while looming-eyes buoys reduced bycatch occurrence by approximately 59% relative to control deployments. Targeted deployment of AWDs has substantial potential to reduce seabird bycatch while minimising disruption to fishing operations.

## Repository contents

- `data/` – datasets used in analyses
- `scripts/` – data processing, modelling and figure-generation scripts
- `figs/` – manuscript figures
- `tables/` – manuscript tables
- `plots/` – intermediate outputs and exploratory analyses
- `images/` – supplementary graphics and images

## Reproducing the analyses

Analyses were conducted in R.

To reproduce the workflow:

1. Clone this repository.
2. Open `AWD-accepted.Rproj`.
3. Run scripts in the `scripts/` directory.
4. Figures and tables will be generated in their respective output folders.
